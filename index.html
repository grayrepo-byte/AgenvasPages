macOS / Linux · Docker Compose v2

核心功能

从灵感到成品，画布承担全部环节

生成、复用、编辑与审批都发生在同一张画布上，不需要在多个工具之间搬运素材。

画布创作

拖拽、框选、连线与自动整理，支持上传本地媒体，卡片关系一目了然。

多模态生成

文字、图片、视频、音频逐卡片运行，支持排队、取消、重新生成与历史版本。

Agent 协作

读取绑定上下文、编辑文字、摆放卡片；媒体生成提案经你批准后才执行。

素材复用

项目资源、个人资产库、提示词模板、媒体风格与混合参考输入，一次沉淀处处可用。

图片处理

标注、裁剪、旋转、镜像、放大、深度提取，以及配置能力支持的 AI 编辑。

自托管管理

模型配置、本地及 OSS / COS / S3 存储、任务与调用记录、项目清单导出。

快速开始

三步，跑起你自己的画布

启动和登录无需 Git、本地编译环境、GPU、.env 或模型 Key。只需装好 Docker Engine / Docker Desktop，并确认包含 Docker Compose v2。

01

一键启动

选择你的系统，复制整段命令执行。

终端 
$ mkdir agenvas && cd agenvas && \
  curl -fL https://raw.githubusercontent.com/grayrepo-byte/Agenvas/main/docker-compose.yml \
    -o docker-compose.yml && \
  docker compose up -d --wait
命令提示符 
> mkdir agenvas && cd agenvas && ^
  curl.exe -fL https://raw.githubusercontent.com/grayrepo-byte/Agenvas/main/docker-compose.yml -o docker-compose.yml && ^
  docker compose up -d --wait
PowerShell 5.1 / 7 
> & {
  $ErrorActionPreference = 'Stop'
  New-Item -ItemType Directory -Path agenvas | Out-Null
  Set-Location agenvas
  Invoke-WebRequest -UseBasicParsing `
    -Uri 'https://raw.githubusercontent.com/grayrepo-byte/Agenvas/main/docker-compose.yml' `
    -OutFile docker-compose.yml
  docker compose up -d --wait
}

这一步会准备 agenvas 目录、拉取镜像，并等待 Web、API 与 PostgreSQL 三个服务健康。首次下载镜像可能需要几分钟，请保留该目录以便后续维护。

02

创建管理员

本机打开 http://127.0.0.1:8088/setup；从其他设备访问时使用 http://<服务器IP>:8088/setup。填写管理员登录名和密码后即可登录。

初始化状态永久记录在数据库中，重启或停用管理员都不会重新开放。 请先在受控网络完成初始化，再开放公网访问。

03

配置模型，开始创作

在「设置 → 模型配置」添加 OpenAI 兼容端点的模型 ID 与 API Key； 在「媒体配置」创建连接、发布能力并设置默认模型。随后创建项目，通过画布右键菜单添加卡片或上传素材。

日常维护 
$ docker compose up -d --wait   # 启动或更新
docker compose ps             # 查看服务状态
docker compose down           # 停止并保留数据

更新前请备份数据库、媒体、配置与加密密钥。 不要执行 docker compose down -v，它会删除数据和密钥。
