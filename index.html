macOS / Linux · Docker Compose v2 
$ mkdir agenvas && cd agenvas && \
  curl -fL https://raw.githubusercontent.com/grayrepo-byte/Agenvas/main/docker-compose.yml \

Core features

From first idea to finished asset, all on the canvas

Generation, reuse, editing and approval all happen on one canvas, so you never shuttle assets between tools.

Canvas creation

Drag, box-select, connect and auto-arrange. Upload local media and see how every card relates at a glance.

Multimodal generation

Run text, image, video and audio per card, with queuing, cancellation, regeneration and full version history.

Agent collaboration

The agent reads bound context, edits text and places cards. Media proposals run only after you approve them.

Asset reuse

Project resources, a personal asset library, prompt templates, media styles and mixed reference inputs — saved once, reused everywhere.

Image processing

Annotate, crop, rotate, mirror, upscale and extract depth, plus AI edits wherever the configured capability supports them.

Self-hosted administration

Model configuration, local or OSS / COS / S3 storage, task and call records, and project manifest export.

Language models

  • Any OpenAI-compatible endpoint
  • Your own model IDs and API keys
  • Tool-calling diagnostic to verify agent readiness

Media adapters

  • GPT Image and Google Nano Banana
  • Volcano Ark Seedance and Seed Audio

Quick start

Three steps to your own canvas

Starting up and signing in needs no Git, no local build toolchain, no GPU, no .env and no model keys. You only need Docker Engine or Docker Desktop with Docker Compose v2.

01

Launch it

Pick your platform and run the whole command as one paste.

Terminal 
$ mkdir agenvas && cd agenvas && \
  curl -fL https://raw.githubusercontent.com/grayrepo-byte/Agenvas/main/docker-compose.yml \
    -o docker-compose.yml && \
  docker compose up -d --wait
Command Prompt 
> mkdir agenvas && cd agenvas && ^
  curl.exe -fL https://raw.githubusercontent.com/grayrepo-byte/Agenvas/main/docker-compose.yml -o docker-compose.yml && ^
  docker compose up -d --wait
PowerShell 5.1 / 7 
> & {
  $ErrorActionPreference = 'Stop'
  New-Item -ItemType Directory -Path agenvas | Out-Null
  Set-Location agenvas
  Invoke-WebRequest -UseBasicParsing `
    -Uri 'https://raw.githubusercontent.com/grayrepo-byte/Agenvas/main/docker-compose.yml' `
    -OutFile docker-compose.yml
  docker compose up -d --wait
}

This prepares an agenvas directory, pulls the images and waits for the web, API and PostgreSQL services to become healthy. The first pull can take a few minutes. Keep the directory — you will run maintenance from it later.

02

Create the admin

On the same machine, open http://127.0.0.1:8088/setup — from another device, use http://<server-ip>:8088/setup. Fill in an admin login and password, then sign in.

Setup completion is recorded permanently in the database, so restarts or disabling the admin never reopen it. Finish setup on a controlled network before exposing the service to the internet.

03

Configure models and start creating

Under “Settings → Model configuration”, add the endpoint, model ID and API key for your OpenAI-compatible provider. Under “Media configuration”, create connections, publish capabilities and set the default models. Then create a project and add cards or upload media from the canvas context menu.

Everyday maintenance 
$ docker compose up -d --wait   # start or update
docker compose ps             # service status
docker compose down           # stop, keep data

Back up the database, media, configuration and encryption key before updating. Do not run docker compose down -v — it deletes your data and keys.

Stack

Familiar tools, transparent implementation
